A Web application i made, to understand how front-end AND back-end work. 

Stack used:
- SQlite
- html
- css
- js
- python flask
- Deployed using: pythonanywhere.
  
Miscellaneous:
- used prompt engineering to "fill css part" and "save as csv option"

Features: 
- Add and delete database entry from the website itself. Non-IT staff won't need SQLite knowledge.
- Save all query in the form of .csv 
- A view only entry option for members , View Database entries.
- A Control panel for Non-IT staff , Manipulate entries with a small view of entries.
